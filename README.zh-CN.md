# Obsidian Private Share

0.7.0：笔记与附件保留本地，通过自建服务分享，电脑自动直传 VPS 保存附件副本。

## 功能

- 分享、更新、复制链接、取消分享，跨设备同步分享状态。
- 分享管理：修改到期时间、删除分享、查看讨论。
- 分享时选择访问密码、有效期、是否允许评论与确认。
- 电脑自动备份笔记引用的图片、音频、视频和文档，支持进度显示及分片续传。
- 本地文件和引用不改写；分享页面使用已验证的 VPS 链接。
- 配合服务端预览图片、音频、视频和 Excel。
- 加密导入、导出连接配置。
- 附件清理只由用户手动确认，先核对本地笔记及分享页面引用，核实失败保留记录。

## 配置

将 main.js、manifest.json 和 styles.css 安装到 private-share 插件目录，启用插件，只填写：

1. 分享地址，例如 https://share.example.com。
2. 服务提供的连接密钥。

不再设置 AList、局域网备用地址、存储后端、上传目录或自动删除。

设置页提供导入、导出、检查连接、分享管理、检查附件备份并重试，以及手动清理入口。电脑启动、同步完成和定时检查时自动备份；手机不上传，需要把本地附件同步到电脑处理。

没有电脑副本的手机图片分享仍可由分享服务复制图片；其他未备份附件等待电脑处理。手机要本地快速显示，需要同步附件原文件。

## 升级与资料保护

旧分享状态、管理令牌、附件归属和待处理任务迁移保留，废弃连接字段删除。旧加密配置可导入，但只采用分享地址和连接密钥。

清理会检查其他笔记和分享网页引用，无法核实不会删除。历史 VPS 文件须有服务端认可的归属和短码记录。VPS 副本不等于不可删除的历史版本归档。

插件需要配套分享 API 和 VPS 文件服务；默认分片 8 MiB，最大文件 2 GiB，并受服务端剩余空间限制。

配置导出文件包含加密的连接密钥，文件和密码应私下保管，不包含分享管理令牌或附件归属记录。
